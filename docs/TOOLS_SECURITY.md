# Phase 0 tool findings and boundaries

Upstream exposed arbitrary `spawn(command,args)`, unrestricted read/list/search from the working directory, and write confinement using `startsWith(base)`. Prefix siblings and symlinks defeated that write check. Regex search allowed expensive user-controlled expressions and unlimited traversal. Fetch followed redirects without checking addresses; the browser scraper could load private-network subresources.

## Current policy

- `executeCommand` and `scrapeLinkedInJob` are removed from advertisements and resource information. Legacy calls fail closed without starting any process/browser.
- Filesystem tools and HTTP storage share an explicit `SAFE_DATA_DIR`. No cwd fallback or automatic root creation exists. Operators must create an absolute, dedicated, service-owned 0700 directory. Generic roots, system configuration/device paths, symlink roots/ancestors and non-private roots fail closed.
- Each component opens with `O_DIRECTORY | O_NOFOLLOW`. Operations are anchored to opened directory descriptors via Linux `/proc/self/fd`, resisting symlink and parent-path replacement attacks. Subdirectories must also be private/service-owned; final directory realpath must remain inside the canonical root. Other operating systems fail closed pending equivalent confinement.
- Traversal, prefix siblings, dotfiles and credential/key names are rejected, including credential-directory ancestors in the configured root. File opens use `O_NOFOLLOW | O_NONBLOCK`; fstat rejects special files, directories and hardlinks. Writes build and sync a new private 0600 sibling before atomic publication. Overwrites use descriptor-anchored rename, so concurrent readers see complete old/new versions; no-overwrite publication uses an atomic exclusive link and fails if a destination appears concurrently. Existing symlinks, hardlinks and special files are rejected before publication. Only the operation's own temporary file is cleaned up; directory metadata is synced. MCP writes require explicit overwrite consent. HTTP writers explicitly choose overwrite for fixed data filenames.
- Reads/writes are at most 1 MiB. Literal search replaces regular expressions, with max 100 results, 16 directory levels, 1,000 entries, 8 MiB aggregate content, and 4,096 characters per returned match. Enumeration also counts skipped entries. OS errors expose codes without absolute paths.
- Fetch permits public HTTP(S) on standard ports without credentials. URL normalization precedes address checks. All DNS answers must be public; connection lookup pins a validated address while retaining hostname for Host/TLS verification. Redirect destinations are re-resolved/revalidated, max four redirects; HTTPS downgrade is blocked. Loopback, private, carrier-grade NAT, link-local/metadata, multicast, reserved/documentation, mapped/tunnel/NAT64 IPv6 addresses are blocked conservatively. Response size is 1 MiB, time at most 30 seconds covering DNS/redirects/body; compressed bodies are rejected.

## Limits and operation

This is defense in depth, not an OS privilege boundary. Run as a dedicated unprivileged service account, keep the root private and do not place secrets or external mounts inside it. Same-account processes and administrator-controlled mounts remain trusted: a hostile process sharing the account can mutate files the account already owns, including renaming an opened directory after a final check. Outputs are untrusted data, never instructions to run other tools.

Browser scraping remains disabled because initial-URL checks cannot secure JavaScript subrequests, resources, WebSockets and redirects. Re-enabling needs separate network isolation and complete request enforcement. Public-only fetch excludes intranet/local employer pages. Conservative IPv6 exclusions can reject some otherwise public targets.

The original tool tests could not run before edits because dependencies were initially absent. They also made live-network calls and asserted unrestricted command execution. Replacement tests use only temporary fixtures and mocked transport; they never execute commands, launch browsers or contact external hosts. Coverage includes malformed/legacy MCP dispatch, missing roots, traversal/prefix siblings, file/parent/root symlinks, hardlinks, private modes, overwrite consent, concurrent atomic reads/publication, credential-root ancestors, file/result limits, regex-looking literal search, normalized special address forms, mixed DNS, rebinding, redirects to metadata/private targets, connection pinning, streamed body limits and DNS/body deadlines.

Final validation: the 138-test full suite passed, including 42 tool tests and 40 network tests (82 focused boundary cases). A separate native smoke verified 160 complete concurrent reads across 40 atomic replacements, exclusive publication races and temporary cleanup. Repository-wide TypeScript validation is reported in the main Phase 0 report.
